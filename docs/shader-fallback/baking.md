# 焼き込み

[トップページ](../../README.md) > [TAO Optimize VRC Shader Fallback](README.md) > 焼き込み

フォールバック先のシェーダーが使うのは、メインテクスチャです（Toon Standard と Standard では、マテリアルの色も使います）。lilToon の色調補正・メインカラー 2nd・3rd、色のアルファ、アルファマスクは、そのままではフォールバックしたときに反映されません。そこで、必要なマテリアルだけ、ビルド時に複製したマテリアルのメインテクスチャを、これらを焼き込んだテクスチャに差し替えます。元のテクスチャは変更しません。

## メインカラーを焼き込み（詳細設定・初期値: オン）

### 焼き込む内容

- **色調補正**: 色相・彩度・明度・ガンマ、グラデーション
- **メインカラー 2nd・3rd**: 2nd・3rd を使っているとき
- **マテリアルの色（`_Color`）**: Toon・Unlit・Particle など、Toon Standard と Standard 以外のフォールバック先では、マテリアルの色が反映されるかを確認していないため、色も焼き込みます。Toon Standard と Standard は、2nd・3rd を使うときだけ色も焼き込みます。

焼き込んだ色とアルファは、複製したマテリアルの設定から外します（焼き込んだ色調補正・2nd・3rd は無効にします）。そのため、焼き込んだテクスチャと設定が二重に効くことはありません。

### 焼き込まない場合

次の条件に当たるマテリアルは、焼き込むと通常の表示が変わるため、焼き込みません。理由は一覧のアイコンで確認できます。

| 項目 | 焼き込まない条件 |
|---|---|
| 全体 | Windows 以外のビルド。メインテクスチャが 2D テクスチャでない。メインテクスチャに Tiling・Offset・UV スクロールがある。色の設定（`_Color`、メインカラー、2nd・3rd の色）がアニメーションで変わる。lilToon Lite と lilToon 以外のシェーダー |
| 2nd・3rd | UV0 以外の UV を使う。デカール・コピー・ミラー・MSDF などの特殊な表示を使う。ディゾルブや距離フェードを使う。ライティングを使わない。スクロールやデカールのアニメーションがある。AudioLink を使う。色が HDR である。透明度（Alpha Mode）を変える |

「メインカラーを焼き込み」をオフにすると、色調補正（Toon Standard では色相以外）と 2nd・3rd は、フォールバックしたときに反映されません。

## 透明度を焼き込み（詳細設定・初期値: オフ）

### 焼き込む内容

- lilToon の色のアルファ（`_Color` のアルファ）と、アルファマスクを、メインテクスチャのアルファに焼き込みます。焼き込んだ後は、色のアルファを 1 にします。
- 対象は、半透明やカットアウトのフォールバック先（Toon Cutout・Unlit Cutout・Unlit Transparent・Particle・Standard の Cutout・Fade・Transparent）になるマテリアルのうち、メインテクスチャのアルファだけでは、元の表示と透け方や抜け方が変わるものです。

### アルファマスクの扱い

| アルファマスク | 焼き込み |
|---|---|
| なし | 焼き込みます |
| 置き換え | 焼き込みます。マスクの設定は残すので、通常の表示は変わりません |
| 乗算 | 輪郭線がなく、マスクにテクスチャがないときに焼き込みます |
| 加算・減算 | メインテクスチャがなく、輪郭線がなく、マスクにテクスチャがないときに焼き込みます |

「メインカラーを焼き込み」と同じく、Windows 以外のビルドや、アニメーションで変わるマテリアルは焼き込みません。

初期値はオフです。オフのとき、色のアルファやアルファマスクで透かしているマテリアルは、メインテクスチャのアルファだけでは透け方を再現できません。そのため、面として見えるものは不透明に（暗い色の透けた面は Particle に）、そのほかは非表示になることがあります。理由は一覧のアイコンで確認できます。オンにすると、焼き込める場合は透け方を再現して、半透明のフォールバック先を使えます。

## 共通

- **テクスチャの形式**: 元のテクスチャの圧縮形式に合わせて生成します。小さいテクスチャは圧縮しません。
- **DXT1 から DXT5 へ**: 元のテクスチャが DXT1（アルファなし）で、透明度を焼き込む場合は、アルファを持つ DXT5 で生成します。そのため、そのテクスチャのメモリが 2 倍になります（一覧の ⓘ で通知します）。
- **ミップマップ**: 縮小して作るのではなく、元のテクスチャのミップマップから階層ごとに焼き込みます。遠くから見たときの表示を、元の表示に合わせるためです。
- **ミップストリーミング**: 有効にします。
- **テクスチャの数**: 焼き込んだマテリアルごとに、テクスチャが 1 枚増えます。同じ内容の焼き込みは 1 枚にまとめます。
- **読み取り**: 元のテクスチャと同じく、読み取り不可にします。

## 通常の表示への影響

作者の環境の実アバター 3 体を、768×1024 の描画で、焼き込む前と後で比べました。

- 8/255 以上の差があったピクセルは、体で 0.02% 以下、顔で 0.01% 以下でした。
- 差の多くは、色の焼き込みによる数ピクセルの違いです。最大の差は、瞳の一部の数ピクセルで 57/255 でした。
- 透明度の焼き込みだけの場合、テスト用の検証では差は 3/255 以下でした。
