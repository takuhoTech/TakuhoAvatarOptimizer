# Toon Standard に設定する値・ビルド時の動作・制限

[トップページ](../../README.md) > [TAO Optimize VRC Shader Fallback](README.md) > 値・動作・制限

## Toon Standard に設定する値

フォールバックしたときにだけ使われる値を、次のように設定します。これらは、元のシェーダーが宣言していない値です。実機（VRChat の Fallback Shaders）で、このような値が Toon Standard に届くことを確認しています。

| 項目 | 設定する値 | 補足 |
|---|---|---|
| カリング | 元のカリング（`_Culling`） | 両面描画は Off になります |
| 影 | Shadow Ramp（`_Ramp`）、Shadow Tint（`_ShadowAlbedo`）、Shadow Boost（`_ShadowBoost` = 0） | Shadow Ramp は lilToon（Lite を除く）のマテリアルにだけ設定します。影が無効のマテリアルは Flat |
| 明るさ | Min Brightness（`_MinBrightness`）、Limit Brightness（`_LimitBrightness`） | 自動は lilToon の「明るさの下限・上限」から決めます |
| 発光 | Emission Strength（`_EmissionStrength`）、Emission UV（`_EmissionUV`） | 再現できない発光は 0 にします（下記） |
| ノーマルマップ | Normal Map の有効・無効（キーワード `USE_NORMAL_MAPS`） | lilToon で法線マップが有効で、メインテクスチャの Tiling・Offset が初期値のときに有効にします |
| 色相 | Hue Shift（`_HueShift`） | メインカラーを焼き込まず、色相の変更にマスクがないときに設定します。色相以外の色調補正は再現されません |
| 輪郭線 | Outline Thickness（`_OutlineThickness`）、Outline From Albedo（`_OutlineFromAlbedo` = 0） | Toon Standard Outline のマテリアルだけ |

### 影（Shadow Ramp）の生成

生成する Shadow Ramp は、lilToon の影の色を元に、少し濃くしています。lilToon は影の色を光に掛けますが、Toon Standard は影の色に環境光を足すので、同じ色では影が薄く見えるためです。

### 通常の表示で使う値の変更

通常の表示が変わらない場合にだけ、次の値を変更します。

- **Shadow Ramp（`_Ramp`）**: lilToon がフォールバック専用に持つ値です。通常の表示では使われないので、生成した Shadow Ramp に差し替えても通常の表示は変わりません。
- **無効な発光の Emission Color**: Toon Standard は、発光が無効でも Emission Color で発光します。そこで、無効な発光の色を黒にします。その発光の設定がアニメーションで変わる場合は、変更しません。
- **メインテクスチャ**: 焼き込んだテクスチャに差し替えます（[焼き込み](baking.md)）。

### 発光

- 有効な発光のうち、次の条件に当てはまるものだけ、Toon Standard で再現します。
  - 加算（Add）またはスクリーンの合成
  - UV0 または UV1 を使う
  - AudioLink を使わない
  - マスクで半分以上を消していない
- そのほかの発光は、フォールバックしたときは発光しません（Emission Strength が 0）。
- 点滅は、平均の明るさとして扱います。
- Toon Standard の発光色は、保存された値をリニアに変換して使われます。lilToon とは明るさの扱いが違うため、その差は強さで補正します。

### 残存値の除去

現在のシェーダーが宣言していない値（以前のシェーダーの値やキーワードなど）は、フォールバック先に届きます。そのため、ビルド時に取り除きます。カスタムで指定したマテリアルは除きます。

## ビルド時の動作

- **Resolving フェーズ**: 設定を読み取り、コンポーネントを削除します。AAO に未知のコンポーネントとして検出されないようにするためです。顔のメッシュは、結合される前に記録します。
- **Optimizing フェーズ（AAO の後）**: マテリアルを複製し、設定を書き込みます。AAO は、シェーダーが使わないマテリアルの値を取り除くので、その後に書き込みます。
- レンダラーとアニメーションのマテリアルを、複製したマテリアルに差し替えます。
- マテリアルのプロパティのアニメーションは、対象のメッシュごとに調べます。対象を特定できないアニメーションは、すべてのマテリアルに影響するものとして扱います。
- 元のマテリアルとテクスチャのアセットは変更しません。
- コンポーネントの無いアバターのビルドでは、何もしません。
- コンポーネントが複数あるときは、最初の 1 つを使い、警告を出します。EditorOnly のオブジェクトのコンポーネントは対象外です。

## 動作確認の状況

| 項目 | 状況 |
|---|---|
| 元のシェーダーが宣言していない値が、Toon Standard に届く | 実機で確認 |
| 通常の表示が変わらない（焼き込みを含む） | Unity 上で、作者の環境の実アバター 3 体をビルドして比較 |
| 元のマテリアルとテクスチャのアセットが変わらない | Unity 上で、ビルド前後のファイルを比較 |
| フォールバックのプレビュー（Preview Fallback）の表示 | Unity 上で確認（VRChat の表示と完全に同じとは限りません） |
| Particle・Toon・Unlit・Unlit Transparent・Standard 系の見え方 | 確認済み |

## 制限

- 見た目は、VRChat のフォールバック用シェーダーで再現できる範囲に限られます。MatCap、金属の反射、リムライト、逆光ライト、FakeShadow、各種マスク、シェーダーによる頂点の変形は再現しません。
- Toon Standard と Toon には、光の影響を受けるアルファブレンドがありません。そのため、透け感のある明るい色の衣類は、不透明で表示されます（[分類](classification.md#半透明マテリアルの分類)）。
- Toon Standard は、ライトプローブだけで照らされるワールドでは、lilToon より明るく見えることがあります。「明るさの上限」を有効にすると、光の合計はメインカラーより明るくなりません。
- 有効な発光の色は、Toon Standard での扱いが違うため、色味がわずかに変わることがあります（強さは補正します）。
- 金属の反射は再現しないため、光沢のある金属は、元より明るく平らに見えることがあります。
- lilToon Lite は、Shadow Ramp（`_Ramp`）を持たないため影を設定せず、焼き込みの対象外です。lilToon 以外のシェーダーにも、影は設定しません。
- lilToon 以外のシェーダーは、アルファマスクを読み取りません。アルファマスクで透かしているマテリアルは、透け方が実際と違うことがあります。
- 焼き込みは、Windows 向けのビルドだけで行います。
- Standard 系の見た目は、VRChat が引き継ぐ値に依存します。
- フォールバックのプレビュー（Preview Fallback）は近似表示です。Standard のプレビューでは、発光とノーマルマップを表示しません。
