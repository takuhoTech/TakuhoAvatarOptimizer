# TAO Optimize VRC Shader Fallback

[トップページ](../../README.md) > TAO Optimize VRC Shader Fallback

VRChat の Safety でカスタムシェーダーが無効化（ブロック）されたときの見た目が、元の見た目に近くなるように、マテリアルごとに [VRCFallback](https://creators.vrchat.com/avatars/shader-fallback-system/) を設定します。

- **元のマテリアルとテクスチャのアセットは変更しません。** ビルド時に複製したマテリアルに設定します。
- 設定するのは、VRCFallback タグと、フォールバックしたときにだけ使われる値です。通常の表示で使われる値は、通常の表示が変わらない場合にだけ変更します。
- 見た目を詳しく再現できるのは lilToon です（lilToon を元にしたカスタムシェーダーを含みます）。Poiyomi など、そのほかのシェーダーには、描画モード（不透明・カットアウト・半透明）に合ったフォールバック先を設定します。lilToon は必須ではありません。

## 使い方

1. アバター内の任意の GameObject（アバターのルートなど）にコンポーネントを追加します。アバターに 1 つだけ追加してください。複数ある場合は、1 つ目の設定を使い、警告を出します。
2. **基本のフォールバック先** を選びます（初期値: Toon Standard）。必要に応じて、影・輪郭線・明るさを変えます。焼き込みや上書きは、**▼ 詳細設定** で変えられます。
3. **フォールバックをプレビュー**（Preview Fallback）を押すと、フォールバックしたときの見た目がシーンに表示されます（NDMF のプレビュー）。もう一度押すと元に戻ります。
   - NDMF のプレビュー（メニューの Tools > NDM Framework > Enable Previews）が無効のときと、再生中は表示されません。
   - プレビューは VRChat のシェーダーを近似した表示です。実際の表示と完全に同じとは限りません。
4. **検出結果を表示**（Preview Result）を押すと、検出したマテリアルと、設定されるフォールバック先が一覧で表示されます。
   - 一覧の上に、検出したマテリアルの数と、見た目が大きく変わるマテリアルの数が表示されます。
   - 一覧は、フォールバック先ごとにまとまります。「変更なし」は、初期状態では閉じています。
   - 各行には、マテリアル、シェーダーの種類と描画モード（例: `lilToon（Uzumore）｜半透明 2パス`）、フォールバック先の指定が並びます。lilToon のカスタムシェーダーは、カスタムシェーダーの名前を添えて表示します。
   - シェーダーの欄にカーソルを置くと、シェーダーの名前と、半透明・カットアウトのマテリアルで測った値（不透明度、抜けている部分、フォールバック先ごとの元の表示との差など）を確認できます。
   - 行の右のポップアップで、マテリアルごとにフォールバック先を指定できます（[マテリアルごとの指定](#マテリアルごとの指定)）。
   - 補足のあるマテリアルには、アイコンが表示されます。⚠ は見た目が大きく変わる可能性があるもの、ⓘ はそのほかの補足です。内容はアイコンにカーソルを置くと確認できます。
   - EditorOnly のオブジェクトのマテリアルは含みません。
   - アバターのマテリアルやメッシュを変更したあとは、**再検出** を押してください。
5. 実際の表示は、VRChat のアクションメニューの **Options → Avatar → Fallback Shaders** で確認できます。

## 設定項目

影・輪郭線・明るさの下限と上限は、基本のフォールバック先が Toon Standard のときに表示されます。

| 項目 | 内容 |
|---|---|
| **基本のフォールバック先** | 不透明のマテリアルのフォールバック先です。半透明やカットアウトのマテリアルも、同じ系統のフォールバック先にします（[フォールバック先の系統](classification.md#フォールバック先の系統)）。<br>**Toon Standard**（初期値）: 光の影響を受けます。影・輪郭線・両面描画・マテリアルの色を再現できます。<br>**Toon**: 光の影響を受けます。メインテクスチャを表示します。<br>**Unlit**: 光の影響を受けません。半透明を Unlit Transparent でそのまま表せます。両面描画には対応していません。 |
| **影** | Toon Standard の影（Shadow Ramp）の設定です。<br>**マテリアルの影を再現**（初期値）: lilToon（Lite を除く）の影の設定（色・範囲・ぼかし・コントラスト）から、マテリアルごとに Shadow Ramp を生成します。<br>**Flat・Realistic・Realistic Soft・Realistic Very Soft・Toon 2 Band・Toon 3 Band・Toon 4 Band**: lilToon（Lite を除く）のマテリアルに、Toon Standard のプリセットの影を使います。<br>影が無効（`_UseShadow` が 0）のマテリアルは、どの設定でも Flat になります。lilToon Lite と lilToon 以外のシェーダーには、影を設定しません（影なしで表示されます）。 |
| **輪郭線** | 輪郭線のあるマテリアルを Toon Standard Outline にフォールバックさせ、元の太さを設定します。<br>**なし** / **暗い色だけ**（初期値）/ **すべて**。Toon Standard の輪郭線は光の影響を受けないので、「暗い色だけ」では、暗い場所で光って見える明るい色の輪郭線を対象にしません。 |
| **明るさの下限** | Toon Standard の Min Brightness（0〜0.1）です。暗い場所でも保つ明るさを設定します。**自動**（初期値）: lilToon の「明るさの下限」から、マテリアルごとに決めます（lilToon 以外は 0）。 |
| **明るさの上限** | Toon Standard の Limit Brightness です。強い光でも白飛びしないように、明るさを制限します。**自動**（初期値）: lilToon の「明るさの上限」が 1 以下のマテリアルで有効にします（lilToon 以外は有効）。有効にすると、光の合計はメインカラーより明るくなりません。 |

### 詳細設定

▼ 詳細設定 を開くと、次の項目が表示されます。

| 項目 | 内容 |
|---|---|
| **メインカラーを焼き込み**（初期値: オン） | lilToon の色調補正・メインカラー 2nd・3rd を、メインテクスチャに焼き込みます。焼き込みが必要なマテリアルだけが対象です。詳しくは [焼き込み](baking.md) を参照してください。 |
| **透明度を焼き込み**（初期値: オフ） | lilToon の色のアルファとアルファマスクを、メインテクスチャのアルファに焼き込みます。半透明やカットアウトのフォールバック先で、透け方や抜け方を再現するために使います。オフのときは、色のアルファやアルファマスクで透かしているマテリアルが、透けない表示や非表示に分類されることがあります。詳しくは [焼き込み](baking.md) を参照してください。 |
| **設定済みのフォールバック先を上書き**（初期値: オン） | オンのとき、マテリアルに VRCFallback が設定済みでも、フォールバック先を決め直して上書きします。オフのとき、設定済みのマテリアルは変更しません。 |

発光の扱いと、以前のシェーダーの値の除去は、設定にかかわらず行います（[Toon Standard に設定する値](values-and-limits.md#toon-standard-に設定する値)）。

## マテリアルごとの指定

一覧の行の右のポップアップで、マテリアルごとにフォールバック先を指定できます。指定したマテリアルは、自動の判定より優先されます。「自動」に戻すと、指定は取り除かれます。

| 指定 | 設定される VRCFallback | 補足 |
|---|---|---|
| 自動 | 自動で決めた結果 | 初期値 |
| 変更しない | 変更しません | 設定済みの VRCFallback は残ります |
| Toon Standard | `toonstandard` | |
| Toon Standard Outline | `toonstandardoutline` | 輪郭線のあるマテリアル向けです。輪郭線のないマテリアルに指定した場合は、輪郭線の太さを 0 にします |
| Toon | `Toon`（両面描画は `ToonDoubleSided`） | |
| Toon Cutout | `ToonCutout`（両面描画は `ToonCutoutDoubleSided`） | |
| Unlit | `Unlit` | 基本のフォールバック先が Unlit 以外のとき、このマテリアルだけ暗い場所で光って見えることがあります（⚠） |
| Unlit Cutout | `UnlitCutout` | 同上 |
| Unlit Transparent | `UnlitTransparent` | 同上 |
| Standard | `Standard` | Unity の Standard です。lilToon とは光の当たり方が違います（[Standard 系](classification.md#standard-系)） |
| Standard Cutout | `StandardCutout` | 同上 |
| Standard Fade | `StandardFade` | 光の影響を受けるアルファブレンドです（Src Alpha で合成） |
| Standard Transparent | `StandardTransparent` | 乗算済みアルファで合成します（Src Blend が One のマテリアル向け） |
| Matcap | `Matcap` | MatCap の再現は未確認です。金属などの質感は再現されない場合があります |
| Particle | `Particle` | 下の色を暗くする乗算で表示します |
| Hidden | `Hidden` | 表示しません |
| カスタム | 入力した文字列 | 例: `VertexLit`、`UnlitCutoutDoubleSided`。タグの形式は [VRChat のドキュメント](https://creators.vrchat.com/avatars/shader-fallback-system/) を参照してください |
